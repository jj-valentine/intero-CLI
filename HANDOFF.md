## Design Decisions
- **Bar style:** Parallelogram (`▰▱`) default, 4 other styles configurable
- **Git caching:** MD5 of repo path as cache key, 5s TTL in /tmp/
- **Tab title:** Set via ANSI escape to /dev/tty from status line script. Summary generated by separate haiku hook
- **Color palette:** Catppuccin Mocha base + iTerm "valentine" pastels. Rainbow distribution — each section distinct color
- **Sync status:** Nuanced messages (synced/behind/ahead/diverged/stale/no-upstream/merging/rebasing)
- **Fetch staleness:** Uses FETCH_HEAD mtime — novel feature nobody else has built
